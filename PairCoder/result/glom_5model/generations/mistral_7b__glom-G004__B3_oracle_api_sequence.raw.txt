 Here is the Python code for the `restructure` function using the glom library:

```python
from typing import Dict, Any
import glom

def restructure(data: Dict[str, Any]) -> Dict[str, Any]:
    spec = {
        'name': glom.Coalesce('a', ''),
        'items': glom.Length('items'),
        'n': glom.Length('items')
    }

    result = glom(data, spec)
    if PathAccessError in result:
        result = {'name': '', 'items': 0, 'n': 0}

    return result
```
